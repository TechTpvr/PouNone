# PouOne — وب‌سایت

وب‌سایت تک‌صفحه‌ای و استاتیک مجموعه PouOne با محصولات SharePou، RoutePou، PrintPou و ConnectPou.

- فقط HTML + CSS + JavaScript، بدون بک‌اند و بدون ابزار Build
- فارسی و راست‌چین، حالت روشن و تیره، ریسپانسیو
- هیچ پوشه‌ای وجود ندارد؛ همه فایل‌ها کنار هم هستند

## فایل‌ها

```
index.html   صفحه اصلی
style.css    استایل‌ها
app.js       منطق صفحه
config.js    لینک‌های دانلود و اطلاعات تماس (اینجا ویرایش کنید)
products.js  متن کامل محصولات
Vazirmatn.woff2  فونت وزیرمتن (خودتان اضافه کنید)
*.webp *.png لوگوها و آیکون‌ها
```

## فونت وزیرمتن

فایل `Vazirmatn.woff2` را کنار `index.html` قرار دهید. تا قبل از آن، اگر فونت Vazirmatn روی دستگاه نصب باشد از همان استفاده می‌شود و در غیر این صورت Tahoma نمایش داده می‌شود.

## لینک دانلود و اطلاعات تماس

در `config.js` آدرس دانلود هر نسخه و اطلاعات تماس را بنویسید. مقدار خالی یعنی دکمه با برچسب «به‌زودی» غیرفعال می‌ماند و مورد تماس نمایش داده نمی‌شود.
